# MathQuest - Learn Math the Fun Way!

An interactive math learning game with card collection and level progression. Solve math problems to earn formula cards and unlock harder topics!

## How to Play

1. Start at the **Home** screen and tap **Play**
2. Choose a **Grade** level (Early Math through 8th Grade)
3. Pick a **Topic** to practice
4. Solve 5 problems correctly to complete the topic
5. Earn a **Card** (formula/tool) for completing a topic
6. Use cards to unlock harder topics and grades
7. Track your progress in the **My Cards** and **Progress** sections

## Game Features

- **Card Collection System** - Earn math formula cards by completing topics
- **10 Grade Levels** - Early Math, Kindergarten, 1st-8th Grade
- **40+ Topics** - Covering counting, arithmetic, fractions, algebra, and more
- **Progress Tracking** - Stars, accuracy, and completion stats
- **Responsive Design** - Works on desktop and mobile
- **Dark Theme** - Beautiful purple gradient UI with animations
- **Offline Support** - Progress saved in localStorage

## Card System

Each topic awards a unique card when completed. Cards represent math skills:
- **Addition Card** - Unlock addition topics
- **Subtraction Card** - Unlock subtraction topics
- **Multiplication Card** - Unlock multiplication and division topics
- **Fractions Card** - Unlock fraction topics
- **Decimals Card** - Unlock decimal topics
- And many more...

Some topics require specific cards to unlock. Collect cards to progress!
