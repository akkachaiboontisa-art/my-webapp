# My Web App

A simple interactive web application built with HTML, CSS, and JavaScript.

## Features

- **Interactive Counter** - Click to increment and reset a counter
- **Live Clock** - Real-time clock display
- **Color Changer** - Change the background gradient with a button
- **Responsive Design** - Works on desktop and mobile devices

## Technologies Used

- HTML5
- CSS3 (with gradients and animations)
- Vanilla JavaScript

## How to Use

1. Open `index.html` in your web browser
2. Interact with the various features:
   - Click "Increment" to increase the counter
   - Click "Reset" to reset the counter to zero
   - Click "Change Color" to cycle through different background colors
   - Watch the live clock update every second
